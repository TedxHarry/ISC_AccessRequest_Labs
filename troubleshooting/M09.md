## Common problems

| What you see | First check | What proves recovery |
|---|---|---|
| The API call fails before creating work | Check the caller, token, permission, operation path and version using the workbench | The intended caller can perform the permitted operation |
| The caller received acceptance but reports access granted | Read the existing request, review and fulfillment state | The caller distinguishes accepted work from a completed native change |
| A client lost a response and wants to retry | Read existing matching request and target state before resubmitting | The intended work is found or a new submission is justified without disguising duplicates |
