## Common problems

| What you see | First check | What proves recovery |
|---|---|---|
| The review is assigned to an unexpected person | Compare the saved reviewer category and recipient's current manager or item owner | A fresh control routes to the intended reviewer; inspect older tasks separately |
| An owner change did not move a pending task | Inspect that task's Assignees and history instead of assuming the edit reassigned it | The pending task is handled with the supported administrative action and the next request routes correctly |
| A reminder or timeout is claimed without an observed event | Compare the submitted time, effective saved settings and actual event history | The timed event is observed, or remains an unfinished timed check |
