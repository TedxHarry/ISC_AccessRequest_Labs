## Common problems

| What you see | First check | What proves recovery |
|---|---|---|
| VPN is absent from the requester catalog | Check the ordinary-user session, global entitlement requests and the item's saved request setting | The intended user can find VPN while the hidden comparison item stays unavailable |
| A request is pending | Open its current Process and Assignees before checking provisioning | The responsible review stage is identified and the correct reviewer completes the intended action |
| Approval is recorded but access is absent | Follow the matching account activity and inspect the actual group result | The requested membership is present on the correct AD account; approval alone is insufficient |

[Open the guided lab](../guided-labs/AR-015/README.md). Use that lab's people and objects. Numbered Section references below refer to its walkthrough. Preserve later legitimate accounts and assignments when revisiting an earlier lab.

### If the result differs

If one group is missing after approval, inspect that group's operation and exact DN. If removal is unavailable, inspect the assignment's origin and revocability. If a group remains after removal, inspect other assignments and operation results. Do not remove membership manually or request individual groups to disguise an incomplete profile operation.

Find existing grant, denial and removal requests before submitting another. If Liam has the test profile, finish verification and supported removal. If removal is pending, resume its review or operation. Start a new test only after checking both memberships and accounting for earlier requests. Preserve pre-existing access and label exceptions; do not claim clean removal while a group remains unexplained.
