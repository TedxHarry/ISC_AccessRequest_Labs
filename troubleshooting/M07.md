# Troubleshooting Practice: Manage temporary access and removal

Use these checks when a result differs, or return after the guided labs to diagnose the supplied cases. Do not introduce a fault into a working setup unless the exercise explicitly asks you to and provides restoration steps.

[AR-040](M07.md#ar-040) · [AR-041](M07.md#ar-041) · [AR-042](M07.md#ar-042) · [AR-043](M07.md#ar-043) · [AR-044](M07.md#ar-044) · [AR-045](M07.md#ar-045)

## Common problems

| What you see | First check | What proves recovery |
|---|---|---|
| Approved temporary access has not appeared yet | Compare the effective start, time zone and current process stage | The observed target result is checked at the relevant time boundary |
| A removal option is absent | Identify the assignment origin and the access level being inspected | Use the supported removal path for that assignment rather than altering an unrelated grant |
| The wrong one of Sofia's accounts changed | Compare the selected assignment, account DN and native operation target | Only the intended account changes and its baseline result remains correct |
