Use these checks when a result differs, or return after the guided labs to diagnose the supplied cases. Do not introduce a fault into a working setup unless the exercise explicitly asks you to and provides restoration steps.

## Common problems

| What you see | First check | What proves recovery |
|---|---|---|
| The form does not appear | Check the exact requested object and its saved form association | A fresh request for that object presents the intended form |
| A conditional field stays hidden | Compare the controlling answer with the saved condition and effect | Both the matching and nonmatching input branches behave as configured |
| One item seems to use another item's answers | Inspect each item and its submitted answers separately | Each review and resulting operation can be matched to the correct item's data |
