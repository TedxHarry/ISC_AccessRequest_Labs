# Troubleshooting Practice: Investigate fulfillment

Use these checks when a result differs, or return after the guided labs to diagnose the supplied cases. Do not introduce a fault into a working setup unless the exercise explicitly asks you to and provides restoration steps.

[AR-046](M08.md#ar-046) · [AR-047](M08.md#ar-047) · [AR-048](M08.md#ar-048) · [AR-049](M08.md#ar-049) · [AR-050](M08.md#ar-050) · [AR-051](M08.md#ar-051)

## Common problems

| What you see | First check | What proves recovery |
|---|---|---|
| A group change fails with a permission error | Inspect the exact failed operation and scoped AD permissions before changing anything | A fresh justified control succeeds after the narrow permission repair |
| A profile references a group that no longer resolves | Compare the current native group identity with the profile's saved entitlement reference | Grant and removal work for the corrected reference |
| AD and ISC membership disagree | Check the same account/group, native result and latest completed aggregation | The imported account is reconciled with the current native state |
