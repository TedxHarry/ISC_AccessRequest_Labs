## Common problems

| What you see | First check | What proves recovery |
|---|---|---|
| An old Failure label is treated as a current incident | Compare the original activity with a fresh working control and current native state | The historical incident and present service condition are distinguished |
| A request record was closed but the user retains access | Inspect the actual assignment and native membership | Perform the justified supported removal and verify the target; do not equate closure with revocation |
| A multi-item submission has mixed results | Inspect each item's review, activity and native result | Each item has its own explained outcome and unresolved work is not hidden by another item's success |
