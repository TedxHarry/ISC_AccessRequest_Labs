## Common problems

| What you see | First check | What proves recovery |
|---|---|---|
| The workflow is not invoked | Check capability, workflow enablement, exact item association and the matching execution | A fresh request invokes the intended enabled workflow |
| The workflow completed but the decision is unclear | Inspect the Approval Policy output, request decision and native result separately | All three results are explained; workflow completion is not treated as approval |
| The wrong branch or message is used | Compare the actual recipient input, condition and decision output used by the next step | The branch and notification match the actual request outcome |
