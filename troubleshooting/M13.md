## Common problems

| What you see | First check | What proves recovery |
|---|---|---|
| A policy warning is assumed to block access | Inspect the actual enforcement configuration, request outcome and native membership | The observed result establishes whether access was prevented |
| A workflow failure is assumed to prove no grant | Inspect the request outcome and actual target after the isolated test | The denied or stopped request and native absence agree |
| A manual task is complete but imported access differs | Compare fulfillment evidence with the current disconnected register and reaggregation | The reconciled account reflects the completed manual operation |
