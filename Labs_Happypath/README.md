# ISC Access Request Labs — Happy Path

This folder contains the **guided first-success path** for the course.

Use these labs when you want a clear, step-by-step walkthrough that builds the working foundation without deliberate failures, troubleshooting tickets, or recovery exercises.

The original engineering labs under `labs/` remain unchanged and should be used later for troubleshooting, variations, fault injection, and production-style practice.

## Happy Path sequence

1. [AR-001 — Import Acme's HR Records](AR-001/README.md)
2. [AR-002 — Resolve the Manager Hierarchy](AR-002/README.md)
3. [AR-003 — Prepare and Aggregate the AD Lab](AR-003/README.md)

## How to use these labs

For each lab:

1. Confirm the starting state.
2. Follow the numbered steps in order.
3. Stop at every **Check** and confirm the expected result.
4. Capture the requested screenshots and evidence.
5. Complete the final verification before moving to the next lab.
6. Leave the stated configuration in place for the next exercise.

The goal of this path is simple: **build one known-good environment first**. Troubleshooting and incident exercises come later in the full engineering path.
