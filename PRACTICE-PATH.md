# Choose your next practice lab

Start at the first unfinished check. A later lab number does not mean every earlier optional product is required.

Choose [beginner walkthroughs](Labs_Happypath/README.md) or [engineering labs](README.md#labs). Both provide the working steps. Engineering labs add investigation and evidence exercises. Reuse matching course objects when switching folders.

## Core sequence

| Sequence | Complete before moving on |
|---|---|
| AR-001–009 | HR identities, manager links, scoped AD aggregation, baseline provisioning and initial sessions |
| AR-010–033 | Requests, access profiles, roles, visibility, account selection and direct reviews |
| AR-034–039, when native forms are available | Create, attach and test the request form. Otherwise continue to the date or removal work; leave the form requirement off. |
| AR-040–041, when date controls are available | Date validation and real scheduled observations. Keep timed observations open until checked. |
| AR-042–051 | Removal, overlapping assignments, account selection, provisioning faults and reconciliation. Dates/forms are not prerequisites for the underlying AD tests. |
| AR-052–057 | API caller context, submissions, decisions and reporting |
| AR-070–075 | Operational tickets using the evidence generated by the core labs |

Prepare each new requester/reviewer with [AR-008](labs/AR-008/README.md). Existing HR and AD records alone do not establish an ISC sign-in session.
