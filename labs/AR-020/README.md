# AR-020 · Repair an application with no usable access

**Before you start:** AR-019. Use Finance Services and Olivia.

## Diagnose the empty application

1. Save Finance Services' profile associations and enabled/request settings.
2. Remove only its two Finance profile associations and save. Do not delete either profile.
3. As Olivia, search the application and record its resulting catalog behavior. Depending on the catalog view, the app can appear empty or cease to be offered as a useful result.
4. Search the profiles directly. Inspect their enabled state and request settings as administrator. This separates an association fault from a profile fault.
5. Re-add both profiles on the application's Access Profiles tab, save and confirm Enable for Users and both Request Center options remain enabled.
6. Refresh Olivia's catalog after processing. Open Finance Services and verify both business choices return.
7. Compare an existing assignment's target membership before and after the association repair. Editing a catalog association is not a removal request.

**Check:** The restored application offers both profiles without recreating them or changing their IDs.

**Reset:** Restore the original associations and settings. No request submission is needed merely to demonstrate restored choices; reuse the working fulfillment evidence from AR-017.
