# CAP-03 · Practice journal

Keep working notes and screenshots private until secrets and unnecessary personal data are removed. Leave unknown IDs empty. Use Passed, Failed, Pending or Not run; mark Historical and Synthetic evidence separately.

## Starting state

Record the date, tenant/source identifiers, actors, account DNs/GUIDs, actual object IDs, original settings and native memberships. Record capability limitations before interpreting a test result.

Use one row per request or observation, with additional rows for separate items and accounts. Copy a row when needed.

## Handover

Record the proven result, limits of that evidence, unresolved requirements, next owner/action and final native state. Explain each material difference from the expected result. A saved setting or workflow completion is not proof of target fulfillment.
